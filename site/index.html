Three ways to build an app

Pick whatever fits what you already make.

BETA

Satisfaction

W-OS's own language, built to be easier than Swift: no optionals, no generics, plain-English errors. Write logic in .satif and your screens in .satUI, and run it from the Developer app.

Web apps

Already have a website? It can ship as an app with its own window and icon. We review the site, then list it in the store.

Linux apps

Flatpak apps from Flathub can be listed once the team has reviewed them. No W-OS-specific port needed.

You stay in control of your app. So do we.

Reviewed before listing

Nothing reaches the store until the team approves it. Devices only install what is on our signed list.

Updates you can ship

New versions go through the same review and appear for everyone without waiting for an OS update.

Withdrawn safely

If a problem is found, an app can be pulled from the store and marked as no longer available on devices that have it.
